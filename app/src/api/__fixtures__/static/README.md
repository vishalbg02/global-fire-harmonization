# SYNTHETIC test sample

SYNTHETIC test sample, generated by `fire_api.static_export` from `data/fixtures/v0.1.0`; not NASA
observations; never shown as results.

It holds the exporter's compact map files for four SYNTHETIC fixture months (`map/`, with the shared
`cells.json`) next to the API's own `/api/map` answers for the same months (`api-map/`), so that
`../staticData.test.tsx` can check that decoding the first gives exactly the second. The fixtures
carry `synthetic: true` in their `metadata.json`, and the exporter passes that flag through to the
`meta.json` and `manifest.json` it writes (this sample keeps neither file: only the map files).

Regenerate it with `WRITE_STATIC_SAMPLE=1 pytest tests/test_static_sample.py` in `api/`
(`api/tests/test_static_sample.py` fails when the committed sample differs from what the exporter writes).
