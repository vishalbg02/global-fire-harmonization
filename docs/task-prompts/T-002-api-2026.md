## 1. Project context
NASA Space Apps Challenge 2026 team project (Many Witnesses + Witness Stand): harmonize NASA FIRMS hotspot detections from several satellites (`docs/PROJECT_PLAN.md`). FIRMS publishes no 2026 zips, so 2026 must come from the FIRMS area API. This task acquires it; T-003 will normalize it later.

## 2. Task objective
For MODIS, S-NPP and NOAA-20, the whole world from 2026-01-01 to the latest available date is saved as 5-day CSV windows in `data/raw/api_2026/`, using standard (SP) data where FIRMS has it and near-real-time (NRT) data after that. The `data_availability` and `missing_data` responses are saved to `data/raw/availability/`. A request log records every window, its product level, row count and retries, so date coverage can be checked.

## 8. Expected outputs
- `data/raw/api_2026/{SOURCE}/{YYYY-MM-DD}_{DAYS}.csv`, one per window segment.
- `data/raw/api_2026/pull_log.tsv`: source, start date, days, level (SP or NRT), rows, attempts, status.
- `data/raw/availability/data_availability_{YYYY-MM-DD}.csv` and `missing_data_{YYYY-MM-DD}.json` (snapshot date in the name).
- A coverage summary in the PR description.

## 9. Implementation requirements
1. Read the SP and NRT date ranges from `data_availability` first and save that response.
2. Iterate 5-day windows from 2026-01-01 to each sensor's latest available date. Use SP for dates up to its SP `max_date`, NRT after. A window that crosses the boundary is split into an SP segment and an NRT segment, so no date is requested twice.
3. Throttle well below 5,000 transactions per 10 minutes. A world request costs about 18 tiles × 2 (VIIRS) or × 0.5 (MODIS) × days (FIRMS page formula); check `mapkey_status` before and after.
4. Retry with backoff on HTTP 429/5xx and network errors. Treat a 200 response whose body is not CSV (no header row) as a failure, not as empty data.
5. Idempotent: skip segments already saved unless `--force`.
6. Log every request with the key redacted.
7. Never fabricate or fill missing dates. A segment that cannot be fetched is logged as failed and reported.
