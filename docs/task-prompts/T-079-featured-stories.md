## 1. Project context
The new UI (T-072, Member 3) shows five featured quick-picks with a caption each. The Lead wants every number in those captions verified against the products, labelled, and reproducible by a query. Method 0.1.0 and the products are final (D-030 not adopted, D-031 approved); this task changes none of them.

## 2. Task objective
For each featured case: the verdict, % of normal, the 90% interval, the rank where it applies, a plain caption with only verified numbers, and the query that reproduces them. Include the Black Summer explanation (D-031: single cells read "cannot determine" while Australia reads ABOVE) and Indonesia's rank (9 of 21 in 2015-09).

## 8. Expected outputs
`featured.ts` with, per case: id, entity type and id, name, year, month, headline, caption, notes, and the stored facts (verdict, % of normal, estimate, interval, normal range, probabilities, rank where defined, reason codes). The report lists every number with its label and query.

## 9. Implementation requirements
1. Numbers come from the products only; the script recomputes them, so the file is reproducible with one command (`python pipeline/featured_stories.py`).
2. Every number is labelled **[VERIFIED]** (stored value or a count by query); outside context (event names) is labelled **[CONTEXT, not from the products]** and kept to a few words.
3. Displayed numbers follow the inventory: % of normal as a whole number (half rounds up); probabilities at the app wording (0.995 or more reads "more than 99%"); estimates and intervals as whole cell-days. Units: Aqua-equivalent cell-days.
4. **Rank** is the position in the app's anomaly list for the type and month: the stored verdicts ABOVE or BELOW only, ordered by the documented API order (`anomaly_order`), then the position within the above list. The GLOBAL entity has no rank.
5. **Black Summer:** count the Australian cells of 2019-12 by verdict, and under the D-031 condition (estimate of at least 20 and more than 3 times the baseline p75) how many read `CANNOT_DETERMINE` against `ABOVE_NORMAL`; the caption says why (too little history in normally quiet cells, D-028 step 4) and that the country reads ABOVE NORMAL.
6. Honest cases: Brazil 2019-08 reads WITHIN NORMAL; the caption says so and does not call it an anomaly. World 2026-10 reads CANNOT DETERMINE (wide interval, provisional, Aqua drift era); the caption says what that means.
7. No claim beyond the method; no causes.
